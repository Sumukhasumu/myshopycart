# MYSHOPYCART

MYSHOPYCART is a learning-focused e-commerce marketplace project designed to demonstrate production-style Java backend development, microservices architecture, distributed systems, API design, security, messaging, observability, Docker, Kubernetes, and cloud deployment.

## Project Status

**Current Phase:** Phase 1 - Development Environment & Repository Setup

The project is currently in the environment and repository setup stage.

No application/service code has been implemented yet.

## Project Goals

The project will demonstrate:

- Java 21 backend development
- Spring Boot microservices
- REST API design
- Authentication and authorization
- PostgreSQL, MongoDB, and Redis
- Kafka and RabbitMQ
- API Gateway and service discovery
- Distributed transactions and Saga patterns
- Docker and Kubernetes
- Automated testing
- Observability and tracing
- CI/CD
- AWS deployment

## Planned Services

The planned backend services include:

- auth-service
- product-service
- inventory-service
- cart-service
- order-service
- payment-service
- notification-service
- api-gateway
- discovery-server
- config-server
